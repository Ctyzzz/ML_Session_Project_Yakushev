# Signal Types Classification

Репозиторий содержит решение задачи кластеризации сигналов сцинтилляционного детектора на три группы: два физических типа сигналов и отдельный кластер неоднозначных событий.

## Что смотреть

1. `01_eda_feature_engineering.ipynb` — анализ исходных сигналов, построение признаков, визуализация распределений и выводы по данным.
2. `02_modeling_submission.ipynb` — обучение и сравнение моделей, подбор параметров, выбор итоговой композиции и создание `submission.csv`.
3. `final_solution.py` — тот же воспроизводимый пайплайн в виде обычного Python-скрипта.

## Как запустить

Установить зависимости:

```bash
pip install -r requirements.txt
```

Затем можно выполнить ноутбуки по порядку или запустить скрипт:

```bash
python final_solution.py
```

После запуска создаются:

- `submission.csv`
- `final_features_with_clusters.csv`

## Структура решения

- из сырых 500 отсчётов сигнала строятся амплитудные, интегральные, PSD- и shape-признаки;
- базовая разметка формируется PCA/PSD-подходом;
- дополнительно сравниваются несколько GMM-моделей на разных наборах признаков;
- итоговая композиция использует базовую модель и локальные согласованные уточнения GMM;
- качество вариантов сравнивается по внутренним метрикам кластеризации и интерпретируемости полученных групп.
